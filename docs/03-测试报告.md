## 四、布局与无障碍用例（`tests/layout.spec.js`）

同一套断言在 375 / 768 / 1024 / 1440 四个视口各跑一遍，共 20 条：

| 用例 | 断言要点 |
|------|----------|
| 页面没有横向滚动条 | `documentElement` 与 `body` 的 `scrollWidth - clientWidth` 均不超过 1px，移动端表格用横向滚动容器而不是撑破页面 |
| 卡片与说明文字不溢出容器 | 遍历指标卡、通用卡片、键值列表、流程项、规则卡、截图卡，`scrollWidth - clientWidth` 不得大于 1px |
| 触控目标尺寸满足 44 像素基准 | 375 / 768 视口下导航链接、标签按钮、分页按钮、下载按钮、搜索框高度均不小于 44px |
| 锚点导航不会被吸顶页头遮挡 | 点击「数据成果」锚点后，目标区块顶部不低于页头高度（减 8px 容差） |
| 正文与次要文字对比度满足 WCAG AA | 概述段落、指标标签与数值、表格正文、规则说明、页脚文字的对比度均不小于 4.5:1，前景背景取实际计算样式 |

## 六、与数据质量的联动结论

测试通过只说明「页面和产物一致」，产物本身的健康度由预处理阶段的 10 条规则给出：

| 规则 | 结论 |
|------|------|
| R1 关键字段完整性 / R3 除权除息日不早于公告日 / R4 先登记后除权 / R5 数值非负 / R8 主键唯一 / R9 公告日期合理性 / R10 日期字段可解析 | 7 条全部通过，0 命中 |
| R2 方案内容有效性 | 3 条提示：送股 / 转增 / 派息三项均为 0 的「空方案」记录，保留原样并打标 |
| R6 数值上界合理性 | 13 条提示：贵州茅台每 10 股派息超过 100 元，属于高价股的真实形态，规则按提示保留 |
| R7 明细页与列表页交叉校验 | 1 条提示：中国平安 `601318-2018-05-31#1` 列表页派息 10.0 元与明细页税前红利 2.0 元不一致，源站自身差异，记录保留并留痕 |

17 条问题全部为「提示」级，错误级为 0，因此数据集可直接用于分析；
每条问题都带 `record_id` 与字段名，可一键回溯到原始页面。

## 七、复现方式

```bash
npm install                 # 安装 @playwright/test
python -m http.server 4185 --bind 127.0.0.1   # 也可以交给 playwright.config.js 的 webServer 自动启动
npx playwright test         # 全部用例：48 通过 / 4 按设计跳过
npm run report              # 打开 HTML 报告
```

说明：Windows 环境默认复用系统自带 Microsoft Edge；如需使用 Playwright 自带 Chromium，
先执行 `npx playwright install chromium`，再设置环境变量 `PW_CHANNEL=bundled`。
