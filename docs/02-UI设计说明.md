# UI 设计说明（ui-ux-pro-max 技能）

> 本页面不是「凭感觉调色」，而是先用 `ui-ux-pro-max` 技能生成设计系统，
> 再把令牌逐条落到 CSS 变量与组件上。本文档记录调用过程、检索结果与落地映射。

## 一、技能调用记录

技能目录：`~/.codex/skills/ui-ux-pro-max/`（本地可搜索库：79 种风格、192 套产品配色、
74 组字体搭配、119 条 UX 规则、105 个图标、17 个 GSAP 预设、25 种图表与 22 个技术栈）。

```bash
# 1) 生成设计系统并持久化到仓库
python ~/.codex/skills/ui-ux-pro-max/scripts/search.py \
  "stock dividend data pipeline report" \
  --design-system -p "Sina Dividend Lab v2" -f markdown \
  --variance 3 --motion 2 --density 7 \
  --persist --output-dir <项目根目录>

# 2) 生成页面级适配文件
python .../search.py "stock dividend data pipeline report" \
  --design-system -p "Sina Dividend Lab v2" -f markdown \
  --variance 3 --motion 2 --density 7 --persist --page report-page --output-dir <项目根目录>

# 3) 补充检索：图表形态 / 表格与无障碍 / 实现栈
python .../search.py "dividend trend comparison chart" --domain chart -n 3
python .../search.py "dense data table filter accessibility" --domain ux -n 4
python .../search.py "data table responsive" --stack html-tailwind -n 5
```

生成物：

- `design-system/sina-dividend-lab-v2/MASTER.md`（设计系统主文件）
- `design-system/sina-dividend-lab-v2/pages/report-page.md`（页面级覆盖文件）

### 检索结果如实记录

| 检索 | 结果 |
|------|------|
| `--design-system`（数据管线报告） | 命中：Pattern「Feature-Rich Showcase」、Style「Minimalism & Swiss Style」、工业石板灰 + 股票绿配色、Poppins + Open Sans 字体组合 |
| `--domain chart`（分红趋势图） | 命中 3 条：趋势数据首选折线图，且要求「线型 + 直接标注」而非只靠颜色区分系列；建议提供可见数据表作为无障碍兜底 |
| `--domain ux`（密集表格） | 命中 4 条：移动端表格用横向滚动容器、筛选标签需可换行、避免自动播放媒体、批量操作提示（按需取舍） |
| `--stack html-tailwind`（响应式表格） | **两次检索均为 0 命中**。按技能要求不虚构结果，实现阶段改用技能内置优先级表（无障碍 → 触控 → 性能 → 样式 → 布局 → 字体颜色 → 动效）作为兜底规则 |

## 二、设计系统摘要

- **风格**：Minimalism & Swiss Style —— 网格化、留白克制、高对比、功能优先，适合数据型工具与文档页；
- **版式策略**：Feature-Rich Showcase，按「首屏关键指标 → 实现过程 → 数据 → 质量 → 图表 → 测试」逐层展开；
- **密度**：`--density 7`，间距刻度收紧到 4–72px，服务表格与长文并存的阅读节奏；
- **动效**：`--motion 2`，仅保留进入视口的轻微淡入（位移 12px / 350ms），不做滚动编排；
- **反差**：`--variance 3`，居中容器、左对齐内容，不使用不对称拼贴。

### 字体与动效

- 标题 **Poppins**、正文 **Open Sans**，均由 `scripts/fetch_fonts.py` 下载 latin 子集并自托管
  （`site/assets/fonts/`），保证离线环境与设计系统一致；
- 中文回退到 `Microsoft YaHei / system-ui`，数字使用 `tabular-nums` 对齐表格列；
- 技能给出的 Scroll Reveal 示例依赖 GSAP + ScrollTrigger（需外网 CDN），本项目改用等价的
  `IntersectionObserver` 实现：位移 12px、时长 350ms，并在 `prefers-reduced-motion: reduce`
  下一律关闭动效。

### 技能自带的交付前检查清单（逐条落实）

| 检查项 | 落实情况 |
|--------|---------|
| 不使用 emoji 当图标 | 全部图标为内联 SVG（数据库、搜索、品牌标记） |
| 可点击元素 `cursor: pointer` | 标签页按钮、分页按钮、折叠面板均设置 |
| 悬停状态 150–300ms 过渡 | 导航、按钮、卡片悬停统一 200ms |
| 正文对比度 ≥ 4.5:1 | 由 Playwright 用计算样式逐项计算亮度比并断言 |
| 键盘导航焦点可见 | 全局 `:focus-visible` 轮廓 + 跳转链接 |
| 尊重 `prefers-reduced-motion` | CSS 与脚本双保险关闭动效 |
| 响应式 375 / 768 / 1024 / 1440 | 四个视口都有布局测试用例 |

## 四、设计取舍

1. **趋势图改为小倍数面板**：5 只股票的派息量级差异过大（茅台累计 325.66 元/股 vs 招商银行 19.85 元/股），
   同轴折线会把除茅台以外的曲线压平。改为每只股票一个独立纵轴面板，面板内直接标注最新值，
   既保留趋势可读性，也避免视觉误导。
2. **不引入图表库**：页面数据量与图表复杂度有限，用原生 SVG 生成即可，代价是零依赖、零网络请求；
   交互与无障碍由 `<details>` 数据表兜底，符合技能对图表的无障碍建议。
3. **密度 7 而非 10**：页面同时承担报告与数据查看两种用途，过密会牺牲长文可读性。
