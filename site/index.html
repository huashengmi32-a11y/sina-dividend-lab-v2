    复现指南

    从零复现这套结果

    四步即可在本地重跑整条管线；抓取结果带缓存，重复执行不会重复请求数据源。

    1. 安装依赖

      python -m pip install -r requirements.txt
npm install

    2. 抓取原始页面

      python scripts/fetch_sina.py

      列表页与明细页全部存入 data/raw/，并生成抓取清单。

    3. 清洗并生成数据集

      python scripts/preprocess.py

      输出 CSV / JSON / Excel 与质量报告，控制台会打印十条规则的命中情况。

    4. 跑测试并打包页面

      npx playwright test
python scripts/sanitize_report.py
python scripts/build_site.py

      测试会生成 docs/screenshots/ 下的截图与 HTML 报告，随后脱敏报告并打包页面数据。
